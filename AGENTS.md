# Instructions for AI Agents

## Overview

Performance testing tool for [RabbitMQ](https://www.rabbitmq.com/) using the [AMQP 0.9.1 protocol](https://www.rabbitmq.com/tutorials/amqp-concepts.html).
It is built on top of the [RabbitMQ Java client](https://github.com/rabbitmq/rabbitmq-java-client).

Consult the [documentation](https://perftest.rabbitmq.com) to learn about how this tool is supposed to be used.

## Supported Java Versions

PerfTest supports Java 8+, so the main code must compile and run on Java 8.
Some features require Java 11+, their code is in `src/main/extensions` and is compiled only on Java 11+ (`extensions` Maven profile).

## Build

```bash
./mvnw clean test-compile
```

To build the uber JAR (`target/perf-test.jar`):

```bash
./mvnw clean package -P uber-jar -Dgpg.skip=true -Dmaven.test.skip
```

## Sanity Check

```bash
./mvnw test-compile
```

### Running Tests

Tests require a RabbitMQ node on `localhost:5672` with the default `localhost`-scoped credentials (`guest`/`guest`).
The broker start script expects a checkout of [tls-gen](https://github.com/rabbitmq/tls-gen) in the `tls-gen` directory:

```bash
ci/start-broker.sh
```

```bash
./mvnw verify -Drabbitmqctl.bin=DOCKER:rabbitmq
```

To run a single unit test:

```bash
./mvnw test -Drabbitmqctl.bin=DOCKER:rabbitmq -Dtest=PerfTestTest
```

To run a single integration test:

```bash
./mvnw verify -Drabbitmqctl.bin=DOCKER:rabbitmq -Dtest=NoTest -Dsurefire.failIfNoSpecifiedTests=false -Dit.test=PerfTestIT
```

## Repository Layout

* `src/main/java/com/rabbitmq/perf`: the tool implementation
* `src/main/java/com/rabbitmq/perf/metrics`: metrics collection and formatting
* `src/main/extensions/com/rabbitmq/perf`: Java 11+ features (e.g. instance synchronization)
* `src/test/java/com/rabbitmq/perf`: unit tests (`*Test.java`, run by Surefire)
* `src/test/java/com/rabbitmq/perf/it`: integration tests (`*IT.java`, run by Failsafe)
* `src/docs/asciidoc`: documentation
* `html`: HTML performance tools to run benchmarks and display results
* `scripts`: launch scripts

## Key Files

Under `src/main/java/com/rabbitmq/perf/`:

* `PerfTest.java`: entry point, command line options definition and parsing
* `PerfTestMulti.java`: entry point to run several scenarios from a JSON specification
* `MulticastParams.java`: settings of a run, creates producers, consumers, and topology
* `MulticastSet.java`: creates connections and starts producers and consumers
* `Producer.java`, `Consumer.java`: publishing and consuming logic
* `Stats.java`, `metrics/PerformanceMetrics.java`: collection of performance metrics
* `ScenarioFactory.java`, `SimpleScenario.java`, `VaryingScenario.java`, `RateVsLatencyScenario.java`: scenarios for `PerfTestMulti`

## After Completing a Task

### Iterative Reviews

After completing a task, perform up to twenty iterative reviews of your changes.
In every iteration, look for meaningful improvements that were missed, for gaps in test coverage, and for deviations from the instructions in this file.

If no meaningful improvements are found for three iterations in a row, report it and stop iterating.
